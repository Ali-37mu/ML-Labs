## Project Structure

The project is divided into three main notebooks, each focusing on a specific stage of the data journey:

1.  Matplotlib: 
     Focuses on the fundamentals of plotting.
     Includes: Possession vs Goals scatter plots, and Home/Away shots comparison using Bar Charts.
     Simple and direct visualizations.
 
2. Seaborn:
    Uses the Seaborn library for more aesthetic and statistical graphics.
    Includes: Distribution plots (KDE), Joint plots for regression, and Correlation Heatmaps.
    High-level statistical analysis.

3.  EDA:
     A deep dive into the data "investigation" phase.
     Includes: Data cleaning (handling missing values & attendance formatting), Outlier detection using Box plots, and finding hidden patterns in match results.

## Dataset: Premier_League.csv
The dataset contains detailed statistics for Premier League matches, including:
* Goals Scored (Home/Away)
* Possession Percentage
* Shots on Target
* Attendance
* Fouls and Cards
